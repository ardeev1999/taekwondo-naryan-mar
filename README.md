# Тхэквондо GTF — Нарьян-Мар

Адаптивный лендинг детской секции тхэквондо: спортивный плакат, крупная типографика, лаймовый акцент и AI-иллюстрация. Автор концепта — Вячеслав Ардеев. Разработка выполнена с помощью OpenAI Codex, иллюстрация — ImageGen.

[Посмотреть сайт](https://taekwondo-naryan-mar.vercel.app)

## Демонстрационный проект

На странице представлены информация о занятиях, путь новичка, блок тренера, FAQ и демо-форма. Форма не собирает персональные данные и ничего не отправляет. Реальные контакты, адрес, расписание и стоимость не опубликованы. Иллюстрация не является фотографией воспитанника. Сайт не является официальным сайтом федерации.

## Запуск локально

Откройте `index.html` в браузере или запустите статический сервер из корня проекта:

```sh
python3 -m http.server 8080
```

Затем откройте `http://localhost:8080`. Установка зависимостей и сборка не нужны. Шрифт Manrope загружается через Google Fonts; при недоступности используется Arial.

## Публикация на Vercel

Импортируйте этот репозиторий в новый проект Vercel и укажите:

- Framework Preset: **Other**.
- Root Directory: корень репозитория.
- Build Command: оставить пустой (сборки нет).
- Output Directory: **`.`**.

Нажмите **Deploy**. Переменные окружения не требуются.

## Файлы

- `index.html` — структура страницы.
- `style.css` — стили и адаптивная вёрстка.
- `app.js` — локальный демонстрационный сценарий.
- `hero.png` — AI-иллюстрация.

Проверены синтаксис JavaScript, три варианта демо-формы, внутренние якоря и наличие локальных ресурсов. Визуальная проверка на разных экранах пока не завершена из-за сбоя инструмента предпросмотра.
